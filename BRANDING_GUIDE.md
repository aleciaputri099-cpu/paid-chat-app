# 🎨 ChatPay - Branding Guide

## 📱 Application Name
**ChatPay**
- Tagline: *"Chat Smart, Pay Smart"*
- Color Scheme: Blue & Purple
- Emoji: 💬

## 🎯 Brand Identity

### Primary Colors
- **Blue**: `#3B82F6` (RGB: 59, 130, 246)
- **Purple**: `#A855F7` (RGB: 168, 85, 247)
- **Gradient**: Blue → Purple

### Secondary Colors
- **Success**: `#10B981` (Green)
- **Warning**: `#F59E0B` (Amber)
- **Danger**: `#EF4444` (Red)

### Accent Colors
- **Coin Gold**: `#FBBF24` (Yellow)
- **Light Background**: `#F3F4F6` (Gray)

## 📐 Typography

- **Logo Font**: Bold, Modern
- **Heading Font**: Semibold, Clean
- **Body Font**: Regular, Readable
- **Font Family**: Segoe UI, Roboto, System Font

## 🎨 Logo Concept

```
💬 ChatPay
  ↓
Conversation bubble with coin symbol
Blue to Purple gradient
Modern, minimalist design
```

## 📝 Tagline Usage

**Primary**: "Chat Smart, Pay Smart"
**Secondary**: "Premium Communication Platform"
**Features**: 
- "Connect & Get Rewarded"
- "Your Time, Your Value"
- "Communication with Purpose"

## 🌐 Brand Voice

- **Tone**: Friendly, Professional, Trustworthy
- **Personality**: Modern, Innovative, Value-Focused
- **Language**: Clear, Concise, Action-Oriented

## 📱 UI Elements

### Buttons
- Primary: Blue Gradient
- Secondary: Gray
- Danger: Red
- Disabled: Gray (60% opacity)

### Icons
- Use React Icons
- Size: 16px (small), 20px (medium), 24px (large)
- Color: Match button/context

### Cards
- White background
- Subtle shadow
- Border radius: 8-12px
- Padding: 16-24px

## 📊 Visual Hierarchy

1. **Primary CTA**: Bold, Gradient, Large
2. **Secondary CTA**: Outline, Medium
3. **Tertiary**: Text Link, Small

## 🎯 Application Pages

### Authentication Pages
- Login: Blue gradient background
- Register: Blue gradient background
- Logo centered, prominent

### Main Application
- Header: Logo + Navigation
- Sidebar: Navigation menu
- Main content: White background
- Footer: Light gray background

## 💰 Coin System Styling

- **Coin Icon**: 🪙
- **Color**: `#FBBF24` (Gold/Yellow)
- **Display**: Large, prominent
- **Badge**: Small circles with count

## 🎥 Video Call Styling

- **Background**: Dark (Black/Dark Gray)
- **Controls**: Light overlay
- **Buttons**: Gradient or Solid
- **Status**: Green (online), Gray (offline), Red (busy)

## 📚 Font Sizes

- **H1**: 32px
- **H2**: 28px
- **H3**: 24px
- **Body**: 16px
- **Small**: 14px
- **Extra Small**: 12px

## 🎨 Component States

### Active
- Highlighted color
- Shadow effect
- Slightly larger

### Hover
- Slightly darker
- Cursor pointer
- Smooth transition

### Disabled
- Gray color
- 60% opacity
- No cursor pointer

### Loading
- Spinner animation
- Gray overlay
- Disabled state

## 📱 Responsive Breakpoints

- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px

## 🎯 Brand Guidelines Summary

✅ Use ChatPay branding consistently
✅ Maintain color scheme across app
✅ Use professional language
✅ Keep UI clean and minimalist
✅ Prioritize user experience
✅ Show coin value prominently
✅ Make actions clear and obvious
